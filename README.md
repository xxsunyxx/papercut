this tool that can run locally or on a server.
It's a small utility to cut downloaded A3 roll paper into A4 sheets.
I only know "vibe coding" (visual/low-code development), so please use tools like Trae and Claude to deploy it.
Before starting, run setup.bat first, but it might not cover all dependencies — you'll need Node.js installed.
For those who prefer Windows Terminal, you can use wtstart.bat, otherwise just use start.bat.

This is a local/server‑side utility that converts downloaded A3‑sized PDF pages into multiple A4 pages.
The project is designed with "vibe coding" – it can be set up with minimal coding experience, using deployment helpers like Trae and Claude.
Before launching, execute setup.bat (though it may not install everything, so ensure Node.js is already installed).
To run the tool, you can either use wtstart.bat (if you have Windows Terminal) or simply run start.bat.
